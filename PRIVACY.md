# Privacy

LinkedIn Quiet stores one setting: the profile identifier you explicitly save. It is stored locally in Chrome extension storage, not synced by this extension.

The extension reads rendered profile/author links on LinkedIn pages to decide what to reveal. It does not send any data to a server, use analytics, read cookies, request credentials, or retain page content. No remote code is loaded.

Removing the extension removes its local settings. Masking content does not prevent LinkedIn itself from downloading content or processing your ordinary use of its service.
